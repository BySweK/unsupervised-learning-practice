# Gözetimsiz Öğrenme Genel Çalışma

Bu proje, Makine Öğrenmesi öğrenme sürecimde, Kaggle üzerinden aldığım **Country Data Set** kullanarak gözetimsiz öğrenme alanında pratik yapma adımlarımı içermektedir.

## 🛠 Kullanılan Teknolojiler
* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Jupyter Notebook

## 📊 Proje Adımları
1. **Veri Keşfi:** Veri setinin yapısal analizi, bağımsız değişkenlerin grafik üzerinde dağılımının incelenmesi.
2. **Yol Haritası** Fazla kolon sayısının model üzerindeki önemini görebilmek adına PCA kullanılmadan ilerlenilmesi.
3. **Genel Gözetimsiz Öğrenme Modellerinin Eğitimi:** Hierarchical,DBSCAN,KMeans gibi modellerin eğitimi ve parametle keşfi
4. **Kıyaslama:** Eğitilen modellerin farklı koşullarda ürettiği sonuçların kıyasının yapılması
